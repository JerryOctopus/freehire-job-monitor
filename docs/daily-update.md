# 每日更新任务

以下为调度平台或代理的任务说明示例。将工作目录替换成自己的克隆路径，设置每日运行一次；时间以 Asia/Shanghai 为准。

1. 读取 `monitor-policy.json`、`search-plan-v2.json` 与 `board.py export-all`，保留用户决定。
2. 通过自己授权的 FreeHire 连接核对筛选项，执行全部 7 路查询，不用技能作为主查询硬门槛。
3. 每轮创建独立 `runs/<日期-时间>/`，每页立即保存 id、args、total、offset、jobs 和抓取时间。按实际 total 读取所有分页，不因遇到旧岗位提前结束。
4. manifest 写入本轮 UTC 起点及起点前 14 天的 cutoff，记录每路 total、rows_read、offsets 和 errors。检查点应能恢复；缺页不能称完成。
5. 运行 `python3 -B finalize_fullscan.py --scan-dir <本轮目录>`。核对职责、最低总经验不超过 5 年、地点与常驻中国的远程资格；排除实习。字段不明需保持待核实。
6. 如需简历匹配，只在本地依据用户确认的经历做要求–证据分析。区分证据不足和真实缺口，不输出无依据的匹配百分比。
7. 通知前重新运行 `python3 board.py export-active`。已投递、不合适不出现在主列表或通知中；换来源/slug 也需检查历史身份。决策库读取失败则停止推送，不能当作无历史。
8. 对比上次结果，仅通知未屏蔽的新增与重要变更；无变化保持安静。失败或需要用户处理时说明原因。

任务只搜索、维护看板和分析，不实际提交求职申请。每日 09:00 启动、目标 09:45 前完成属于调度目标，执行时间取决于连接和数据量。
